# Shade Lab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (preserved Native method) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Four Shade images from one revised block (scaled-down-adult framing + explicit ear bans) across four seeds, judged against Arm C's Shade at the same control seed — with production defaults byte-identical throughout.

**Architecture:** A lab-owned `shade-lab/descriptions.md` holds the single revised block; a small `build_shadelab.py` reuses `build_arm_b`'s parser/frame/addendum constants (plus a new exported `FRAME_C`) to emit four entries (`shade_s0..s3`, each with its own `seed`); `build_sheet_workflows` learns per-entry seed plumbing (defaults unchanged); the runner's setup guard relaxes to "at least one"; `verify_sheettest` gains an optional `--roster` (default = the six arm slugs).

**Tech Stack:** inherited unchanged.

**Spec:** `docs/superpowers/specs/2026-11-01-sheet-test-design.md` — "Shade Lab directive" section is binding.

## Global Constraints

- Revised Shade block = the Arm B Shade block verbatim + this addition (before `exactly two arms`): `full-size adult human features scaled down uniformly to half size, same proportions as a grown man, small rounded human ears, no pointed ears, no elf ears, no large ears, no protruding ears`
- Lab frame = Arm C frame (byte-identical, imported from production), addendum unchanged.
- Seeds, exactly: `424242` (control vs Arm C Shade), `424243`, `777001`, `314159` → entries `shade_s0..shade_s3`.
- Production defaults stay byte-identical: builder without `--seed` → 424242; verifier without `--roster` → the six arm slugs; runner's arms behavior unchanged (guard only loosens); existing parity/byte-compare tests must stay green without modification.
- Arms A/B/C frozen — no writes to `img/`, `arm_b/`, `arm_c/`, or `sheettest_{,b_,c_}*.json`.
- `prompts.json` nine-key schema; lab `arm: "C"`; no `bible.md`/`refs/`/`gallery` tokens in any script.

## Review Focus

1. **Revised block wording drift** (clause missing/mangled) — pinned by `test_shadelab.py::test_revised_block_pins_fix` (ear bans + scaled-down clause verbatim; chunk still verbatim) and `::test_prompt_is_exact_composition`.
2. **Seed plumbing silently changing arms** — pinned by existing `test_round1_defaults_untouched` + `test_nondefault_cli_round_trip` byte-compares (run untouched) and new `::test_build_one_honors_entry_seed`.
3. **Lab artifacts wrong shape** — pinned by `::test_lab_prompts_schema` (four keys, exact seed ladder, arm C, frame C) and `::test_lab_workflows_family`.
4. **Verifier/runner contract weakening** — pinned by `::test_default_roster_unchanged` (six-roster default still gates) in `test_record_output.py`; runner change is parse-checked and ledgered.
5. **Arms A/B/C mutation** — freeze `git diff` over their paths at Task 2 (verification step).
